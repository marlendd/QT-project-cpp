# Функции языка программирования

Qt-приложение для управления базой данных функций языков программирования. Курсовая работа по дисциплине ООП (вариант 10).

## Описание

Приложение позволяет создавать, редактировать и управлять записями о функциях различных языков программирования. Каждая функция характеризуется типом возвращаемого значения, именем, списком аргументов и комментарием.

## Возможности

- Создание, редактирование и удаление записей о функциях
- Поиск по таблице в реальном времени
- Сохранение и загрузка данных в формате CSV
- Объединение данных из нескольких файлов
- Просмотр данных в текстовом формате
- Пользовательский интерфейс на Qt Widgets

## Технологии

- C++14
- Qt 5/6 (Core, GUI, Widgets)
- Шаблонные классы (Vector, Function)
- Итераторы STL

## Структура проекта

- `Function.h/cpp` - класс, описывающий функцию языка программирования
- `Vector.h` - шаблонный класс динамического массива
- `mainwindow.h/cpp` - главное окно приложения
- `add_dialog.h/cpp` - диалог добавления/редактирования функции
- `show_data.h/cpp` - диалог просмотра данных
- `icons/` - иконки для интерфейса

## Сборка

### Требования

- Qt 5.x или Qt 6.x
- Компилятор с поддержкой C++14 (GCC, Clang, MSVC)
- qmake или Qt Creator

### Инструкция

```bash
qmake MyCourse.pro
make
```

Или откройте `MyCourse.pro` в Qt Creator и нажмите "Build".

## Использование

1. Запустите приложение
2. Используйте меню "Файл" для создания нового файла или открытия существующего
3. Добавляйте функции через кнопку "Добавить" или меню
4. Редактируйте записи двойным кликом или через меню "Правка"
5. Используйте поле поиска для фильтрации записей
6. Сохраняйте изменения через меню "Файл" → "Сохранить"

## Формат данных

Данные сохраняются в CSV-файлах с разделителем ";" и следующей структурой:

```
Тип функции;Имя;Число аргументов;Аргументы;Комментарий
int;sum;2;a, b;Сумма двух чисел
void;print;1;text;Вывод текста
```
